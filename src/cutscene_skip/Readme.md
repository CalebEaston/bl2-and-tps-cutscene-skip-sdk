## Changelog

### Cutscene Skip v0.1
- First version. `Always Skip Cutscenes` skips every in-game cutscene as it starts and stops
  full-screen videos (DLC intros, endings) from playing. The `Skip Cutscene` key, unbound until
  you set it, skips the in-game cutscene that is playing. Everything the mod does is written to
  the console and to `unrealsdk.log` with a `[Cutscene Skip]` prefix. Borderlands 2 and The
  Pre-Sequel; neither has been play-tested yet.
